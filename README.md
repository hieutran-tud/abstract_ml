# abstract_ml

This repository contains experimental code for simple ML models and GAN experiments used for learning and teaching purposes.

Contents
- `src/` - Python package with models, trainers, and utilities.
- `script/` - Jupyter notebooks to run experiments (GANs, MNIST classification, etc.).

Quick start
1. Create and activate a Python virtual environment.
2. Install dependencies (not specified here; install numpy, matplotlib, etc.).
3. From the project root, open notebooks in `script/` and run cells.

Notes about pushing to GitHub
- The `src/mnist/data/` folder is excluded by `.gitignore` because it contains raw dataset files.
- To push this repository to GitHub, add a remote and run `git push -u origin main` (or provide a remote URL).
